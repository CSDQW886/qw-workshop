## 重新出包

```bash
cd 02-源码
apktool b . -o build/qw-u127.apk -f
# 再执行 03-脚本/build_v127.py（需把脚本里的路径指到本目录）
```

签名：`we.keystore` / alias `we` / 口令 `123456`（脚本内已写死，正式发布请换自己的 keystore）。

## 已知限制（如实标注）

1. 手机（小屏）布局只做到代码级保证，未做真机宽度实测。
2. 「提取项目中的图片」只对含 `scene.pkg` 的场景类作品展示，视频 / 网页类不展示，这是设计如此。
3. 国内网络大概率连不上 Steam，本应用不内置任何代理 / 加速服务；下载只走 Steam 官方 content server。
