## ⚠️ 使用前必读

### 1. 国内网络大概率连不上 Steam

本项目**不内置任何代理、也不内置任何加速服务**。Steam 社区与 CDN 在国内多数网络下会超时或被重置，表现为「加载不出来 / 一直转圈 / 登录失败」。
**请自行准备 VPN 或加速器**，并确认设备能正常访问 `steamcommunity.com`、`api.steampowered.com`、`steamusercontent.com` 后再使用本应用。

### 2. 下载只走 Steam 官方 CDN

所有作品文件都通过 **Steam 官方下载通道（content server）** 传输，**不经过任何第三方服务器**，账号密码也不会发给除 Steam 以外的任何地方。

### 3. 必须登录自己的 Steam 账号才能下载

创意工坊原项目下载需要账号身份校验：

- **不登录**：可以浏览列表、看详情、放大预览图、**下载封面**。
- **登录后**：可下载作品原文件（需你已合法拥有 Wallpaper Engine 及对应内容的访问权限）。

一次登录同时建立「网页会话」与「下载会话」，不需要登录两遍。

### 4. 隐私与凭据处理

- 密码**不落盘**，只在内存中用于生成 Steam 登录请求。
- 登录成功后**不保存明文账号**，本地只存打码后的显示名（如 `c***58`）用于界面显示。
- 不采集、不上传任何个人数据；无第三方统计 / 上报 SDK。

## 功能

- 创意工坊作品列表：搜索、排序、场景 / 类型 / 内容分类 / 年龄分级多选筛选（条件本地记忆）
- 详情页：封面大图、作者、订阅数、简介，双击查看原图
- 下载封面 / 下载原项目（断点续传、进度、暂停 / 继续、重试）
- 下载管理：多选批量删除、打开所在目录、重新下载
- 场景类作品支持「提取项目中的图片」（`scene.pkg` 解包导出到 `图片/`）
- 手机 / 平板双端自适应：默认手机 2 列、平板 4 列，可手动切 2 / 3 / 4 列

## 下载目录

```
/storage/emulated/0/QW-Workshop/<作品ID>/
```

- 每个作品一个文件夹，文件夹名就是创意工坊作品编号。
- 提取的图片在该目录下的 `图片/` 子目录。
- 若系统不允许写入公共目录，会自动改存到应用专属目录（设置页「诊断」里能看到真实路径）。

## 权限用途

| 权限 | 用途 |
| --- | --- |
| `INTERNET` | 访问 Steam 页面与接口、下载作品文件 |
| `ACCESS_NETWORK_STATE` | 判断网络状态，给出可读的错误提示 |
| 所有文件访问权限（可选） | 把内容写入 `/storage/emulated/0/QW-Workshop/` |

除上述之外不申请、不采集任何数据。

## 从源码构建

工程是「apktool 反编译基座 + 前端资源重写」的混合结构：`assets/` 下的 HTML / CSS / JS 是应用界面与逻辑，`smali/` 是桥接层。

```bash

# 一键构建（apktool b → zipalign → 签名）
./tools/build.sh

# 只想出未签名包
apktool b . -o build/qw-unsigned.apk -f

# 带自己的 keystore 直接出签名包
KS=./qw.keystore ALIAS=qw PASS=你的口令 ./tools/build.sh

```

产物：`build/qw-s127.apk`（zipalign + apksigner 校验通过），签名 `CN=WE Preview`，与旧版同签名可覆盖升级。

## 目录结构
